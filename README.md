# DropΩ  🚀 | Build 3
https://readme-glich.github.io/Drop-/
**DropΩ** — это легковесное и быстрое приложение на **Python** для удобного обмена файлами в локальной сети между устройствами на Windows. Программа позволяет легко раздавать файлы как через встроенный сетевой протокол, так и делиться ими через обычный браузер.


[![Поддержать на Boosty](https://shields.io)](https://boosty.to/readmeddev)



Код приложения сгенерирован с помощью искусственного интеллекта (AI) и успешно протестирован на персональном компьютере разработчика.

---

## ✨ Основные возможности
* **Два режима раздачи:** 
  * Прямая передача (TCP через приложение) для отправки файлов на ПК с установленным DropΩ.
  * Раздача по HTTP для скачивания файлов любым устройством через обычный веб-браузер.
* **Гибкий поиск:** Автоматическое обнаружение отправителя по заданному порту или ручной ввод IP-адреса и порта.
* **Кастомизация порта:** Возможность вручную назначить рабочий порт передачи (по умолчанию используется `5000`).
* **Выбор пути сохранения:** Настройка папки для приема файлов прямо в интерфейсе.
* **Темы оформления:** Поддержка светлой, темной и системной тем интерфейса.

---


## 🛠️ Стек технологий
* **Язык программирования:** Python
* **ОС:** Windows (тестировалось локально)
* **Архитектура:** Использованы сетевые библиотеки для работы с TCP/HTTP-протоколами.

---


> ⚠️ **Важно:** Для успешной отправки и получения файлов устройства должны находиться в **одной локальной сети** (быть подключены к одному Wi-Fi роутеру или соединены кабелем). При первом запуске разрешите приложению доступ в сеть в брандмауэре Windows.
