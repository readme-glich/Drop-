Удобный обмен файлами в локальной сети

Легковесное и быстрое приложение на Python для Windows. Раздавайте файлы в один клик через приложение или обычный браузер.

Основные возможности

Два режима раздачи

Прямая передача: TCP через приложение на ПК с DropΩ.
HTTP-раздача: скачивание любым устройством через обычный браузер.

Гибкий поиск

Автоматическое обнаружение отправителя по заданному порту или ручной ввод IP-адреса и порта для точного соединения.

Кастомизация порта

Возможность вручную назначить рабочий порт передачи прямо перед запуском сессии (по умолчанию используется порт 5000).

Путь сохранения

Удобная настройка папки для приема файлов прямо в графическом интерфейсе приложения.

Темы оформления

Интерфейс поддерживает светлую, темную, а также системную тему для комфортной работы в любое время суток.

Важная информация

Для успешной отправки и получения файлов устройства должны находиться в одной локальной сети (быть подключены к одному Wi-Fi роутеру или соединены сетевым кабелем). При первом запуске обязательно разрешите приложению доступ в сеть в брандмауэре Windows.
